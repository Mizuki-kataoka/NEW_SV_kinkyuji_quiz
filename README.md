# NEW_SV_kinkyuji_quiz
SV緊急時対応クイズの最新版です。

◎サイト概要
  ・index.html　最初にページを開いたときに出るホーム画面的なやつです。いろいろなクイズに飛べます。
  ・SV_1-5.html　初級の地震編です。
  ・SV_1-6.html　ミスってるやつです。何も書かないでください。
  ・SV_2-1.html　初級の危険行為を行う人物編です。
  ・SV_3-1.html　初級の病人・ケガ人が店内で発生編です。
  ・SV_4-1.html　初級のその他突発的な自然災害が発生編です。
  ・SV_1-5_mid.html　中級の地震編です。
  ・SV_2-1_mid.html　中級の危険行為を行う人物編です。
  ・SV_3-1_mid.html　中級の病人・ケガ人が店内で発生編です。
  ・SV_4-1_mid.html　中級のその他突発的な自然災害が発生編です。
  ・SV_kinkyu1.css　サイト全体のデザインを決めているファイルです。
  ・firebase-config.js　回答データをインタネット上に保存するために必要です。編集しないでください。
  ・modify_quiz.js　回答データをインタネット上に保存するために必要です。編集しないでください。

◎SV項目がアップデートされたとき
クイズの文章を編集して保存すれば、簡単にクイズ内容を書き換えられます。
今書いてあるのを参考にしてAIにでも聞いてください。
